# 🏏 Admin Live Panel (Cricket Scoring System)

## 📌 Project Description

This module allows the admin to update cricket scores in real-time using a ball-by-ball scoring system.

---

## ❗ Problem Statement

Manual score updating systems are slow and not interactive.
This project provides a real-time admin panel to update scores instantly.

---

## ✨ Features

* Match creation
* Ball-by-ball scoring
* Score update buttons (0,1,2,4,6,W,NB,WD)
* Automatic strike change
* Over calculation
* Real-time updates

---
